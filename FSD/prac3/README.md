# Practical 3: JavaScript fundamentals

This page demonstrates JavaScript functions, objects, arrays, and string operations. A greeting function uses your input, an object supplies the student profile, an array stores the topic list, and the string demo recalculates its output as you type.

## Run and try it

1. Open `index.html` from this folder in your browser. You can also open it through your editor's local web server.
2. Submit a name under **Functions**, inspect the **Objects** card, add a topic under **Arrays**, and edit the text under **String Operations**.

The page runs in the browser. It needs no npm install or backend server.
