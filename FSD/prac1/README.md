# Practical 1: HTML elements and multimedia

This page shows how an HTML document uses its head and body. It includes hyperlinks, text formatting, an image, a table, ordered and unordered lists, and browser audio and video controls. The audio and video files are bundled in `media/`.

## Run and try it

1. Open `index.html` from this folder in your browser. You can also open it through your editor's local web server.
2. Use the navigation links to jump between examples. Scroll to **Multimedia** and play the audio and video.

The page runs in the browser. It needs no npm install or backend server.
