# Practical 2: Web form and CSS selectors

The course registration form demonstrates CSS selectors, pseudo-classes, and pseudo-elements. CSS styles the field focus, selected radio option, and the submit button's generated decoration. Native HTML validation checks required fields and the email format.

## Run and try it

1. Open `index.html` from this folder in your browser. You can also open it through your editor's local web server.
2. Try submitting an empty form to see required-field validation. Then enter a name and email, choose a course, select a learning mode, and accept the terms. The form is a frontend demonstration and does not store submissions.

The page runs in the browser. It needs no npm install or backend server.
