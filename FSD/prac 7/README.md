# Practical 7: Node.js setup and basic programs

These scripts verify that Node.js can run JavaScript outside the browser. They print a greeting, perform arithmetic operations, and display a student record using an object and a function.

## Run the scripts

1. Install Node.js and open a terminal in this practical folder. Run `node --version` to check that Node.js is on your PATH.
2. Enter the project directory and run each script:

   ```powershell
   Set-Location -LiteralPath 'NodeJS_Practical'
   node hello.js
   node arithmetic.js
   node student.js
   ```

3. Read the results in the terminal. This practical needs no npm install, server, or browser.
