# al-fsd-ves5

Semester V Full Stack Development practicals 1–13 and the CA 3 example projects.

To get a standalone copy of the files:

```sh
npm pack al-fsd-ves5@1.0.1
tar -xzf al-fsd-ves5-1.0.1.tgz
```

Open the applicable directory under `package/`. Practicals 1–4 are standalone
HTML pages. Practicals 7–8 are Node.js scripts. The React and server projects
each have their own dependencies and start commands in their `package.json`.
See each project's README and environment template where applicable.

The CA 3 programs are under `CA 3/source`.
