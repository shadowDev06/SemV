# Practical 4: JavaScript events and form validation

The student registration form uses event listeners, a validator class, and a custom error class. The validator handles field changes and submission, shows errors beside invalid inputs, and clears the form after a successful submission.

## Run and try it

1. Open `index.html` from this folder in your browser. You can also open it through your editor's local web server.
2. Submit the blank form to see the first validation error. Then enter a valid name and email, a 10-digit phone number, a course, and a message of at least 20 characters. Accept the terms and submit to see the confirmation.

The page runs in the browser. It needs no npm install or backend server.
